# Απομαγνητοφώνηση — ασφαλής υπηρεσία

Το αρχείο `cloudflare-worker.js` είναι ο ασφαλής ενδιάμεσος διακομιστής. Το κλειδί OpenAI **δεν** μπαίνει ποτέ στο GitHub Pages ή στις ρυθμίσεις του browser.

## Εγκατάσταση (μία φορά)
1. Δημιούργησε Worker στο Cloudflare και επικόλλησε το περιεχόμενο του `backend/cloudflare-worker.js`.
2. Στις ρυθμίσεις του Worker πρόσθεσε Secret με όνομα `OPENAI_API_KEY` και τιμή το προσωπικό API key σου.
3. Κάνε Deploy και αντέγραψε τη διεύθυνση Worker (π.χ. `https://....workers.dev`).
4. Άνοιξε το Learning Center → Ρυθμίσεις → Αυτόματη απομαγνητοφώνηση και αποθήκευσε αυτή τη διεύθυνση.

## Σημαντικό για μεγάλα σεμινάρια
Η υπηρεσία OpenAI File Transcription δέχεται έως 25 MB ανά αρχείο. Ο Worker απορρίπτει μεγαλύτερο αρχείο με σαφές μήνυμα και δεν εκθέτει το API key. Για πολυώρες ηχογραφήσεις απαιτείται πρόσθετη διαδικασία συμπίεσης/διαχωρισμού ήχου σε έγκυρα αρχεία έως 25 MB πριν από την αποστολή. Η απλή αποκοπή των προσωρινών MediaRecorder fragments δεν είναι ασφαλής, επειδή δεν είναι κατ' ανάγκη αυτοτελή αρχεία ήχου.

Η χρήση της υπηρεσίας API μπορεί να χρεώνεται από τον πάροχο. Έλεγξε τις τρέχουσες τιμές πριν από εκτεταμένη χρήση.
